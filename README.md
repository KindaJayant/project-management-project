# PM-OS | Project Management Operating System

![PM-OS Banner](https://images.unsplash.com/photo-1550751827-4bd374c3f58b?auto=format&fit=crop&q=80&w=1200)

PM-OS is a state-of-the-art Project Management workspace designed for the high-frequency demands of 2026. Built with a premium glassmorphic interface and integrated with an AI Project Advisor, it offers a real-time, high-fidelity view of your project's health.

## 🚀 Core Features

- **Strategic Dashboard**: High-contrast visualization of Budget Health, Risk Indices, and Team Velocity.
- **AI Project Advisor**: Integrated LLM support using the Arcee Trinity Large model for real-time strategic insights.
- **Analytical Optimization**: One-click AI-driven state refinement to keep your project benchmarks aligned with 2026 standards.
- **Risk Register**: Predictive assessment and mitigation strategy tracking.
- **Timeline Planning**: Dynamic Gantt-style roadmap with status tracking.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite
- **Styling**: Vanilla CSS with Glassmorphism and Backdrop Blurs
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **AI**: OpenRouter (Arcee Trinity Large)

## 🏁 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/KindaJayant/project-management-project.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment**:
   Create a `.env` file in the root and add your OpenRouter API key:
   ```env
   VITE_OPENROUTER_API_KEY=your_key_here
   ```

4. **Launch Dev Server**:
   ```bash
   npm run dev
   ```
